**Feed Remover** is a simple and fun extension that removes LinkedIn feed posts and replaces them with a cute cat 😻, dog 🐶, or both 😻🐶. It helps reduce distractions and keeps you focused on what actually matters.

Tired of scrolling through the same boring posts on LinkedIn? Feed Remover is for you.


## Features ⭐
- Show/Hide Feed in a few clicks or just use Shortcut `Ctrl + Shift + Y`.
- Hides simple ads from the Feed.
- Fully supports both Dark Mode and Light Mode.
- Preserves the standard LinkedIn feed layout.
- Choose between cats, dogs or both.
- Choose between infinite scrolling or a single pet post.
- Random funny phrases to brighten your day.
- Lightweight and easy on system resources.
- Always free and completely ad-free.


## Development 💻

Run `npm run build` after making changes to compile TypeScript into JavaScript.

**Firefox:**

* Go to `about:debugging` in Firefox.
* Click **This Firefox** on the left.
* Click **Load Temporary Add-on**.
* Browse to the location of the unzipped folder and select the `manifest.json` file.

**Chrome:**

* Go to `chrome://extensions` in Chrome.
* Enable **Developer mode** using the toggle on the right.
* Click **Load unpacked** on the left.
* Browse to the location of the unzipped folder and select it.

You can find the Firefox and Chrome builds under **Releases**.


## Usage 🖥️
To use Feed Remover, click the icon in the top right corner of your browser. A pop-up window will appear with a toggle in the middle, just click and the extension should work fine.
You can also use the shortcut CTRL + Shift + Y to toggle Show/Hide feed content.

The extension should start blocking feed content after installation. If not, make sure you are granting the extension the necessary permissions.
